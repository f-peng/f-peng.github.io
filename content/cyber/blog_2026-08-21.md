## La journée du 21 août 2026 marque une vague de vulnérabilités critiques et élevées, avec des failles déjà exploitées dans des solutions majeures comme GitLab, Microsoft Entra ID ou Keycloak. Les correctifs se multiplient, mais leur déploiement urgent reste une priorité absolue pour les équipes de sécurité.

## 🇫🇷 En France
- **ANSSI** : alerte sur la vulnérabilité **CVE-2026-69836** dans Microsoft Entra ID, activement exploitée et permettant une exécution de code arbitraire à distance, [CERT-FR](https://www.cert.ssi.gouv.fr/avis/CERTFR-2026-AVI-1074/).
- **Cyberveille e-santé** : signale une faille d’**injection de code** dans SPIP (**CVE-2026-77647**), liée à une identification incorrecte des blocs PHP, [Cyberveille e-santé](https://cyberveille.esante.gouv.fr/alertes/spip-cve-2026-77647-2026-08-21).

## 🌍 À l’international
- **Microsoft** : la faille **CVE-2026-69836** dans Entra ID, notée **CVSS 10**, est déjà exploitée dans la nature, mais aucun correctif utilisateur n’est requis, [IT-Connect](https://www.it-connect.fr/entra-id-cve-2026-69836-faille-cvss-10-exploitee/).
- **GitLab** : la vulnérabilité **CVE-2026-19478** fait l’objet de tentatives d’exploitation **48h après la publication du correctif**, [IT-Connect](https://www.it-connect.fr/gitlab-cve-2026-19478-faille-critique-exploitee/).
- **Keycloak** : la faille **CVE-2026-18963** permet de **réinitialiser le mot de passe de n’importe quel compte** sans authentification, un patch est disponible, [IT-Connect](https://www.it-connect.fr/keycloak-cve-2026-18963-faille-critique-mot-de-passe-oublie/).
- **Citrix** : la vulnérabilité **CVE-2026-19490** dans NetScaler ADC et Gateway permet un **contournement d’authentification à distance**, [IT-Connect](https://www.it-connect.fr/citrix-netscaler-cve-2026-19490-contournement-authentification/).
- **Elementor Pro** : la faille **CVE-2026-32475** permet à un visiteur anonyme d’**exécuter du code PHP** via un formulaire, affectant les sites WordPress, [IT-Connect](https://www.it-connect.fr/elementor-pro-cve-2026-32475-rce-non-authentifiee/).

## Conclusion
La journée du 21 août 2026 confirme une **tendance inquiétante** : l’exploitation **ultra-rapide** de failles critiques, comme pour GitLab (CVE-2026-19478) ou Entra ID (CVE-2026-69836). Les équipes doivent **prioriser les correctifs** pour les solutions exposées (NetScaler, Keycloak, Elementor Pro) et surveiller les indicateurs de compromission. L’absence de scores CVSS pour plusieurs vulnérabilités souligne aussi l’urgence de **valider les alertes officielles** (ANSSI, Cyberveille e-santé) pour évaluer les risques.
